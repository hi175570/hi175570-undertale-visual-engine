# Workspace 拖动连线与运行按钮（2026-10-09）

## 要求与实现

- 拖动整张列表或拆分后缀时，贝塞尔连接不消失，端点跟随可见的移动部分；原位置仍不重复绘制拖走的部分。
- 连线仍按原 target_list_uid 建立，只用 WorkspacePortPosition 根据临时拖动坐标投影端点。拖整列时入口/出口一起移动；拆后缀时只移动对应步骤的出口，原列表头和前缀不动。取消后自然恢复，无需改写存档、连接或执行数据。
- 遍历连线不再使用“原位置可见步骤数”筛掉拖动部分，目标头也不因原位置隐藏而被跳过。保持原 UID lookup 和线性遍历，不对每条边重复搜索项目。
- 运行按钮固定为列表头同底色、有边框、原像素字体。独立画布控件不再根据 x>=420 等位置误套 Inspector 样式。按钮大小、文字、内边距、圆角及边框厚度一起缩放，不再因物理宽度变小把运行截成三个点；点击范围保持原逻辑坐标。
- 拖动预览也绘制移动端口和相同运行按钮；空列表拖动不再越界读 steps[0]。
